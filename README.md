# OCTIQ landing page

موقع تعريفي ثابت لمشروع OCTIQ، الاسم الجديد لمشروع SAHLA. يحتوي على HTML وCSS وJavaScript وصور الشعار. لا يحتاج إلى خادم خلفي أو قاعدة بيانات لعرض الصفحة.

## محتويات الحزمة
- `index.html`: الصفحة الكاملة ومحتواها.
- `styles.css`: التصميم المتجاوب والحركات.
- `script.js`: تبديل اللغة، تأثيرات التمرير، شريط التقدم، وقائمة الهاتف.
- `assets/octiq-logo.png`: الشعار المستخدم في ترويسة الموقع والأيقونة.
- `assets/octiq-brand-high-resolution.png`: نسخة الشعار عالية الدقة المستخدمة في القسم الرئيسي.
- `assets/octiq-logo-original.jpg`: الصورة الأصلية للشعار.
- `assets/octiq-connected-world.png`: الصورة الأولى المرسلة، وتظهر في قسم المشهد المتصل.
- `assets/octiq-future-ecosystem.png`: الصورة الثانية المرسلة، وتظهر في قسم رؤية المنظومة المستقبلية.

## مهم: لماذا يظهر localhost؟
`localhost` يعني أن الصفحة تعمل على جهازك أنت فقط، غالبًا لأنك فتحتها باستخدام خادم محلي للتجربة. لن تبقى متاحة للآخرين بعد إطفاء جهازك إذا كانت مستضافة بهذه الطريقة.

## نشر الموقع مجانًا ليبقى متاحًا وجهازك مطفأ
1. فك ضغط ملف ZIP.
2. ارفع **محتويات المجلد** إلى مستودع GitHub، بحيث يكون `index.html` في جذر المستودع، ومجلد `assets` بجانبه. لا ترفع المجلد الخارجي كطبقة إضافية.
3. من المستودع افتح `Settings` ثم `Pages`.
4. اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/(root)`، واضغط `Save`.
5. انتظر انتهاء النشر. سيعطيك GitHub رابطًا عامًا ينتهي عادةً بـ `github.io`. افتح هذا الرابط وليس `localhost`.
6. لربط دومينك: من `Settings → Pages` أدخل الدومين في `Custom domain`، ثم أضف سجلات DNS التي يطلبها GitHub لدى مزود الدومين. فعّل HTTPS عندما يصبح متاحًا.

بعد نشر GitHub Pages بنجاح، يستضيف GitHub الملفات على خوادمه، لذلك يبقى الموقع متاحًا حتى عندما يكون جهازك مطفأ، ما دام المستودع والنشر والدومين يعملون بشكل صحيح. لا تشغّل `python3 -m http.server` إذا كنت تريد رابطًا عامًا دائمًا؛ هذا الأمر للمعاينة المحلية فقط.
